# api-diff

Breaking-change detector for OpenAPI specs, as a CLI and a GitHub Action. It's mainly a learning project; for production use, see oasdiff.

**Status:** spec only, not implemented yet. See [PROJECT_SPEC.md](PROJECT_SPEC.md).

Built following [../../ENGINEERING_STANDARDS.md](../../ENGINEERING_STANDARDS.md). No benchmarks, users or downloads are claimed until they're measured.
